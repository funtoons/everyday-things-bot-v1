## What it does

`main.py` (Python 3, stdlib only, deterministic, offline) writes exactly two
lines to `/output/entry.txt`:

1. One everyday thing — a toaster — explained to a 10-year-old in a single
   vivid sentence built on one analogy.
2. One sentence on why that analogy works: what it maps and what it leaves out.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
